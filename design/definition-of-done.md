# Definition of Done

- [ ] The tool is connected and has the right design file open.
- [ ] There is a desktop frame at 1440px.
- [ ] There is a mobile frame at 390px.
- [ ] Repeated controls use components / instances.
- [ ] Variables or existing design tokens are reused.
- [ ] Required states are shown or marked N/A.
- [ ] The design is approved by a human before implementation.
- [ ] The implementation lives in the existing screen, not in a separate demo route.
- [ ] The behavior from `design/brief.md` is not broken.
- [ ] Project typecheck / lint / build pass as far as they exist in the repo.
- [ ] Desktop and mobile are checked in the browser.
- [ ] `git diff --stat` contains only the expected scope.
